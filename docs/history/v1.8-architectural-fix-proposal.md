# v1.8 Architectural Fix Proposal — Root Cause Analysis

The US5215088 evaluation report is **materially corrupted** due to cross-patent contamination, hardcoded values from a previous evaluation, and missing architectural invariants. This document traces every defect to its root cause and proposes concrete fixes.

## Root Cause #4: No Target Identity Validation

**Symptom**: Report evaluates US5215088 but contains US8527057 data

**Root Cause**: `contract.py` validates section structure but NOT:
- Target patent identity consistency
- Evidence provenance (which patent does this evidence belong to?)
- Cross-run contamination detection

**Fix**: Add Target Identity Firewall to contract.py:
```python
@dataclass(frozen=True)
class TargetIdentity:
    publication_number: str
    application_number: str
    title: str
    inventors: tuple[str, ...]
    assignee: str
    filing_date: str
    grant_date: str

def validate_target_identity(
    sections: list[ReportSection],
    target: TargetIdentity,
    evidence_items: list[dict]
) -> list[ContractError]:
    """Verify all evidence belongs to the target patent."""
    errors = []
    for evidence in evidence_items:
        if evidence.get('target_publication_number') != target.publication_number:
            errors.append(ContractError(
                "Evidence Provenance",
                evidence.get('evidence_id', 'unknown'),
                f"Foreign evidence: {evidence.get('source_patent')} "
                f"does not match target {target.publication_number}"
            ))
    return errors
```

## Root Cause #5: No Epistemic State Machine

**Symptom**: "All propositions established" contradicted by "No established findings" sections

**Root Cause**: The system has a single `status` field that collapses:
- ESTABLISHED (fact with evidence)
- PARTIALLY_ESTABLISHED (some evidence)
- INFERRED (LLM reasoning)
- NOT_LOADED (no data fetched)
- UNKNOWN (insufficient evidence)

**Fix**: Implement multi-dimensional epistemic state:
```python
@dataclass
class EpistemicState:
    # Primary states
    ESTABLISHED: str = "ESTABLISHED"      # Evidence-backed fact
    PARTIAL: str = "PARTIALLY_ESTABLISHED" # Some evidence
    INFERRED: str = "INFERRED"            # LLM reasoning, no direct evidence
    NOT_LOADED: str = "NOT_LOADED"        # No data fetched
    UNKNOWN: str = "UNKNOWN"              # Insufficient evidence
    
    # Confidence levels
    HIGH: str = "HIGH"
    MODERATE: str = "MODERATE"
    LOW: str = "LOW"
    
    # Source types
    DIRECT_EVIDENCE: str = "DIRECT_EVIDENCE"
    DERIVED: str = "DERIVED"
    BENCHMARK: str = "BENCHMARK"
    ASSUMPTION: str = "ASSUMPTION"
```

## Root Cause #7: No Pre-Render Integrity Gate

**Symptom**: Corrupted report rendered successfully

**Root Cause**: `contract.py` validates structure but not content integrity

**Fix**: Add pre-render integrity gate:
```python
def pre_render_integrity_gate(
    report_md: str,
    scores: dict,
    submission_md: str
) -> list[ContractError]:
    """Final validation before rendering."""
    errors = []
    
    # 1. Target identity consistency
    target = TargetIdentity(**scores.get('target_patent', {}))
    if not target.publication_number:
        errors.append(ContractError("Target", "identity", "No target patent specified"))
    
    # 2. Evidence provenance
    evidence_items = scores.get('evidence_items', [])
    errors.extend(validate_target_identity([], target, evidence_items))
    
    # 3. Epistemic state consistency
    errors.extend(validate_epistemic_states(scores))
    
    # 4. Derived metrics have evidence
    errors.extend(validate_market_claims([], evidence_items))
    
    # 5. No cross-run contamination
    errors.extend(check_cross_run_contamination(scores))
    
    if errors:
        raise RenderContractFailure(errors)
    
    return errors
```

## Root Cause #9: Legal-Term Calculation

**Symptom**: 2009 expiration instead of 2010

**Root Cause**: Simple `filing_date + 20 years` heuristic applied to pre-1995 patent

**Fix**: Legal-term regime-aware calculation:
```python
def calculate_expiration(filing_date: date, grant_date: date) -> date:
    """Calculate patent expiration with correct term regime."""
    if grant_date < date(1995, 6, 8):
        # Pre-1995: 17 years from grant
        return grant_date + timedelta(days=17*365)
    else:
        # Post-1995: 20 years from filing
        return filing_date + timedelta(days=20*365)
```

## Root Cause #10: FDA Regulatory Semantics

**Symptom**: FDA clearance conflated with therapeutic approval

**Root Cause**: No distinction between:
- FDA-cleared device
- FDA-approved chronic therapeutic BCI
- FDA Breakthrough Device Designation
- Clinical efficacy approval

**Fix**: Regulatory status taxonomy:
```python
@dataclass
class RegulatoryStatus:
    clearance_type: str  # "510(k)", "PMA", "HDE", "IDE", "Breakthrough"
    indication: str      # "short-term monitoring", "chronic implant", etc.
    market_status: str   # "cleared", "approved", "investigational"
    restrictions: list[str]  # ["human use only", "research settings", etc.]
```

## Conclusion

The report is not fixable by editing the markdown. The renderer must be parameterized, the contract must validate identity and provenance, and the epistemic state machine must distinguish facts from inferences. The v1.8 architecture must make this class of failure impossible, not merely detectable.
