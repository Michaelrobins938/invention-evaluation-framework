# Novelty Search — US 7,149,534 B2

## Claim-construction layer

The supplied patent provides formal claims (44 claims, 4 independent). The principal
evaluation targets are independent claims 1 and 23 (apparatus/method for a mobile
terminal that generates GPS assistance data from received GPS data and transmits it
to a remote mobile terminal via the wireless network) and independent claims 15 and
37 (apparatus/method for a mobile terminal that receives GPS assistance data from a
remote mobile terminal and uses it to determine a reference location).

### Independent claim 1 limitations (apparatus, GPS-assistance provider)

- **L1:** a GPS receiver to receive GPS data (satellite signals).
- **L2:** a cellular transceiver to communicate with a wireless communications network.
- **L3:** the mobile terminal generates GPS assistance data from the received GPS data.
- **L4:** the mobile terminal transmits the GPS assistance data to a remote mobile
  terminal via the wireless communications network.

### Independent claim 15 limitations (apparatus, GPS-assistance consumer)

- **L5:** a cellular transceiver to communicate with a wireless communications network.
- **L6:** the mobile terminal receives GPS assistance data via the wireless network,
  the assistance data having been generated by a remote mobile terminal from GPS data
  the remote received.
- **L7:** the mobile terminal determines a reference location based on the received
  peer-supplied GPS assistance data.

### Dependent claim features (representative)

- **D2:** the two terminals are members of a group (hierarchical, sub-groups,
  priorities; ad-hoc; geographic; profile-defined).
- **D3:** trust/privacy profile control over transmission (claim 23/37 limitations).
- **D4:** periodic scheduled refresh and automatic/responsive transmission.

The peer-to-peer mobile-as-server-of-GPS-assistance-data limitation is the structural
delta over the network-fixed-node-assistance prior art.

| L4 transmits GPS assistance data to a remote **mobile** terminal via the wireless network | **No** — assistance data is sent by the *network* to the mobile, not by a *peer mobile* | **No** — same | **No** — same | **No** — mobile sends computed position to a *server*, not a peer mobile, and not assistance data | **Partial** — mobile relays information to a peer mobile, but the information is shop/traffic content, not GPS assistance data | Partial — generic P2P messaging, no GPS assistance content |

**Anticipation gate:** No single reference discloses all four limitations of claim 1.
Each reference misses at least one of: (a) the peer-mobile as the source of the
assistance data (the network-fixed-node references all have a fixed/server source);
(b) the specific content of GPS assistance data (Honda and Traversat have
peer-mobile-to-mobile messaging but not GPS assistance content); (c) generation of
assistance data at the mobile from satellite signals (Zadeh/Kingdon/Pihl generate at
the network side; Pande generates position, not assistance data, at the mobile).
**Claim 1 is not anticipated by the reviewed record.**

## Causal Bridge Test — closest external pathway

Closest single reference pathway: US 6,389,291 (Pande) + US 6,477,353 (Honda)
combination, with general A-GPS knowledge from Zadeh/Kingdon.

```yaml

    known_objective: provide positioning assistance to GPS-equipped mobile terminals

    known_principles: assisted-GPS via fixed network nodes; mobile computes position
      and reports to server; mobile-to-mobile information relay with propagation control
  claimed_state:
    claimed_configuration: a peer mobile terminal generates GPS assistance data from
      satellite signals it receives and transmits that assistance data to a remote
      mobile terminal via the cellular network; the remote mobile uses the peer-supplied
      assistance data to determine its own reference location
    claimed_effect: extend GPS assistance beyond network-fixed-node coverage to peer-
      reachable mobiles, with hierarchical-group/trust/privacy coordination
  bridge:
    required_change: move the assistance-data source from a fixed network node (MLC/
      LMU/server) to another mobile terminal in the cellular network, and add group,

      - "A-GPS literature (Zadeh, Kingdon, Pihl, Krasner): establishes the existence, content, and value of GPS assistance data."

      - "Network-fixed-node assistance may be unavailable in some cells; a peer mobile with good satellite reception can serve as an alternate source."
```
